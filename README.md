# Typelytics
Typelytics is a modern typing test web application built using React and Vite.
It provides real-time typing analysis including WPM, accuracy, timer tracking, and dynamic typing interaction.

## Features
* Real-time WPM calculation
* Accuracy tracking
* Countdown timer
* Dynamic typing interface
* Auto line scrolling
* Responsive UI
* AI integration (work in progress)

## Tech Stack
* React
* Vite
* JavaScript
* CSS
* Gemini API

## Run Locally
```bash
npm install
npm run dev
```
